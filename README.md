# City Dominion

Projeto Roblox de cidade aberta com progressão, empregos, propriedades, economia, veículos, polícia, crime e disputa por domínio territorial.

## Estrutura inicial

- `src/server` — lógica segura do servidor
- `src/client` — HUD, controles e interface
- `src/shared` — módulos compartilhados
- `default.project.json` — configuração Rojo

## Objetivo do protótipo

Criar uma base jogável com:

- dinheiro e progressão
- empregos rápidos
- terrenos e propriedades
- bloqueio de construção sobreposta
- sistema de cidade expansível
- base pronta para veículos, polícia e crime

> O projeto será desenvolvido com assets próprios, oficiais do Roblox ou com licença de reutilização compatível.
